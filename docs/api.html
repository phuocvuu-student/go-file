API Documentation

Integrate Go File into your applications with our RESTful API

Getting Started

Go File provides a RESTful API for programmatic access to file upload, management, and sharing features. All API endpoints support token-based authentication for secure integration.

Quick Start

1

Generate API Token

Login to your Go File instance and navigate to Account Management to generate an API token.

2

Set Authorization Header

Include your token in the Authorization header: Authorization: Bearer YOUR_TOKEN

3

Make API Calls

Use any HTTP client to interact with the API endpoints documented below.

Authentication

Token Authentication

Go File uses token-based authentication. Include your API token in the Authorization header of your requests.

Headers

Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json

Alternative Format

Authorization: YOUR_API_TOKEN

File Upload

POST /api/upload

Upload Files

Upload one or more files to the Go File server.

Parameters

Name Type Required Description
file File Yes The file(s) to upload (multipart/form-data)

cURL Example

curl -X POST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@/path/to/your/file.jpg" \
  http://localhost:3000/api/upload

Python Example

import requests

url = 'http://localhost:3000/api/upload'
headers = {'Authorization': 'Bearer YOUR_TOKEN'}
files = {'file': open('file.jpg', 'rb')}

response = requests.post(url, headers=headers, files=files)
print(response.json())

JavaScript Example

const formData = new FormData();
formData.append('file', fileInput.files[0]);

fetch('http://localhost:3000/api/upload', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN'
  },
  body: formData
})
.then(response => response.json())
.then(data => console.log(data));

Response

{
  "success": true,
  "message": "File uploaded successfully",
  "data": {
    "filename": "file.jpg",
    "url": "http://localhost:3000/file/abc123",
    "size": 1024576,
    "type": "image/jpeg"
  }
}

Image Upload

POST /api/image/upload

Upload Images

Upload images to the built-in image hosting service.

cURL Example

curl -X POST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "image=@/path/to/image.png" \
  http://localhost:3000/api/image/upload

Response

{
  "success": true,
  "message": "Image uploaded successfully",
  "data": {
    "filename": "image.png",
    "url": "http://localhost:3000/image/xyz789",
    "thumbnail": "http://localhost:3000/image/xyz789/thumb",
    "size": 512000,
    "dimensions": {
      "width": 1920,
      "height": 1080
    }
  }
}

File Management

GET /api/files

List Files

Get a list of all uploaded files.

Example

curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3000/api/files
GET /api/file/{id}

Get File Info

Get information about a specific file.

Example

curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3000/api/file/abc123
DELETE /api/file/{id}

Delete File

Delete a specific file from the server.

Example

curl -X DELETE \
  -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3000/api/file/abc123

🔧 Custom Integration

Build your own integration using the API.

Node.js Example

const axios = require('axios');
const FormData = require('form-data');

async function uploadFile(filePath) {
  const form = new FormData();
  form.append('file', fs.createReadStream(filePath));
  
  const response = await axios.post(
    'http://localhost:3000/api/upload',
    form,
    {
      headers: {
        'Authorization': 'Bearer YOUR_TOKEN',
        ...form.getHeaders()
      }
    }
  );
  
  return response.data;
}

Error Handling

HTTP Status Codes

Go File API uses standard HTTP status codes to indicate success or failure.

Code Meaning Description
200 OK Request successful
400 Bad Request Invalid request parameters
401 Unauthorized Invalid or missing authentication token
403 Forbidden Insufficient permissions
404 Not Found Resource not found
413 Payload Too Large File size exceeds limit
500 Internal Server Error Server error occurred

Error Response Format

{
  "success": false,
  "error": "Unauthorized",
  "message": "Invalid authentication token"
}

Rate Limiting

Request Limits

Go File implements rate limiting to prevent abuse. Rate limits can be configured by the server administrator.

Default Limits

  • Upload requests: 100 per hour per IP
  • API requests: 1000 per hour per token
  • File size: 100MB per file (configurable)

Rate Limit Headers

Responses include headers indicating current rate limit status:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1640995200

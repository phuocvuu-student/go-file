  2. Upload files or share folders
  3. Access from any device on the network

Command Examples

Basic Usage

./go-file

Starts Go File on default port 3000

Custom Port

./go-file --port 8080

Run on a different port

Share Folder

./go-file --path ./documents

Share a specific folder

Video Streaming

./go-file --video ./movies

Enable video streaming from folder

Custom Host

./go-file --host 192.168.1.100

Specify IP address for QR codes

No Browser

./go-file --no-browser true

Don't auto-open browser
